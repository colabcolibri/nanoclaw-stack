# NanoClaw (motor)

Motor multi-agente embutido no [nanoclaw-stack](../README.md). Baseado em [NanoClaw upstream](https://github.com/nanocoai/nanoclaw), com customizações Colibri/Barao.

## Desenvolvimento

Use os scripts na raiz do monorepo:

```bash
pnpm dev      # UI + motor local
pnpm ai       # motor + Telegram
pnpm build:agent
```

Documentação operacional: [docs/DEV-LOCAL.md](../docs/DEV-LOCAL.md) e [docs/DEPLOY.md](../docs/DEPLOY.md).
